# AgentGlow — инструкции для Claude

Поведение, статусы и файлы — в `README.md`, прочитать перед правкой. Здесь только правила работы.

Раньше проект назывался ClaudeGlow и показывал только Claude Code; с версии 2.0 это AgentGlow — одна программа с
несколькими источниками событий (Claude Code, OpenCode, универсальный `/status`).

## Устройство

- Ядро (`src\*.cs`): OpenRGB, эффекты, настройки, трей, итоговый статус, приём событий, установщик, обновления,
  отчёты о сбоях. Приложений оно не знает: работает со списком источников.
- Источник — папка `src\Sources\<Приложение>\` с классом, реализующим `IAgentSource` (`IAgentSource.cs`), и, если у
  приложения есть что прописывать, классом `IIntegration`. Регистрация — одна строка в `SourceCatalog.All`: из
  каталога строятся галочки установщика, шаг деинсталлятора, блоки меню трея, ключ `sources` в `settings.txt`.
  Источники: `Claude` (хуки Claude Code, адрес `/hook`), `OpenCode` (плагин, адрес `/opencode`), `Generic`
  (`/status`).
- Один приёмник `EventListener` на `127.0.0.1:47651` раскладывает запросы по адресу. Проверка заголовка
  `X-AgentGlow: 1` (если источник `RequiresMarker`) и `Host` — в нём же. `OnReceive` источника вызывается на потоке
  приёма, пока соединение открыто (Claude по нему находит процесс), `Handle` — на UI-потоке.
- Статусы общие (`GlowStatus`), эффект и цвет — на статус (`AppSettings.Effects`). Источник выражает своё состояние
  только через общие статусы: своих статусов, цветов и эффектов у источника нет. Подсветка не показывает источник.
- Плагин OpenCode — `plugin\agentglow.js`, вшивается ресурсом `AgentGlow.Plugin.js`; `{{PORT}}` подменяет
  `OpenCodePlugin.Install`. Первая строка (`// AgentGlow plugin version=N port=P`) — признак «наш файл» и версии:
  поменял поведение плагина — подними `OpenCodePlugin.CurrentVersion` и `VERSION` с заголовком в плагине.

## Сборка

- Штатный `csc.exe` .NET Framework 4.8, **C# 5**: нет `$"..."`, `?.`, `nameof`, `=>`-членов,
  инициализаторов авто-свойств, `out var`.
- Собирать `build.cmd nostart` (все `src\**\*.cs` через `/recurse`). Без `nostart` вызов из Bash висит, пока
  программа запущена.
- `build-installer.cmd` в конце удаляет `AgentGlow.exe` из корня репозитория — после него для запуска из
  репозитория снова нужен `build.cmd nostart`. Установщик и деинсталлятор компилируют весь `src` (список — в
  `installer\obj\src.rsp`, без `AssemblyInfo.cs`) с `/main:AgentGlow.SetupProgram` / `.UninstallProgram`: каталог
  источников один для программы и установщика.
- Репозиторий и установленная копия (`C:\Program Files\AgentGlow`) — разные папки. Сборка трогает только свой
  `AgentGlow.exe`: занят — переименовывается в `AgentGlow.old.exe`. Установленный экземпляр обновляется
  установщиком. Два AgentGlow сразу не запустить: второй выходит по мьютексу.

## Проверка

- Синтетические события — `curl` на `127.0.0.1:47651` (примеры в README), результат — `%LOCALAPPDATA%\AgentGlow\log.txt`.
  Запрос на `/opencode` и `/status` без `X-AgentGlow: 1` — 403.
- Хуки в `~/.claude/settings.json` действуют на **все** сессии Claude Code, включая рабочие треды пользователя.
  Не ломать их формат; проверять JSON после правки. Файл может быть симлинком — запись идёт в цель.
- `ClaudeHooks` проверять на копии `settings.json` через `CLAUDE_CONFIG_DIR`: снять → поставить → сравнить набор
  хуков и остальные ключи с исходником (порядок групп внутри события может смениться).
- Плагин OpenCode проверять на настоящем OpenCode: `opencode-cli.exe serve --port 4199` из
  `%LOCALAPPDATA%\opencode`, сессия — POST `/session?directory=<папка>`, запрос — `prompt_async`, разрешения и вопросы
  — `GET /permission`, `GET /question`. В окружении задана `OPENCODE_SERVER_PASSWORD` — нужен Basic-auth. Сервер
  запускать отдельным вызовом без перенаправления вывода в той же команде (инструмент зависает). Созданные тестовые
  сессии удалять (`DELETE /session/<id>`): они попадают в базу пользователя.
- Логику трекеров проверять отдельным консольным exe из файлов трекера источника — без UI и OpenRGB.
- Скриншоты README (`docs\*.png`) — обвязкой на синтетических данных, без реальных путей и имён.
- Протокол OpenRGB проверять python-скриптом в scratchpad до переноса в C#.

## Правила кода

- Комментариев нет, один класс — один файл, `if/else` вместо `switch` на две ветки.
- Ресурсы: таймеры не чаще раза в секунду (сейчас 5 с — живость и переподключение, 15 с — таймауты), запись в
  OpenRGB только при смене эффекта. Исключение, согласованное с пользователем, — кадры плавной пульсации (40 мс), и
  только пока горит пульсирующий статус.
- Плагин OpenCode и журнал не содержат текстов запросов, ответов, команд и вопросов.
- Новое приложение — новая папка в `src\Sources\`, а не правка ядра. Ядро правится, только если интерфейс источника не
  выражает нужное.

## Грабли

- Heredoc в Bash ест обратные слэши — `.cmd` и строки с `\` писать инструментом записи или python-скриптом.
- `.cmd` — CRLF и только ASCII; соседние скрипты и сам `.cmd` вызывать полным путём.
- Инструмент правки переводит файл в CRLF целиком — после правки `TrayApplication.cs` смотреть `git diff --stat`.
- `[IO.File]::ReadAllText('относительный\путь')` в PowerShell читает от каталога процесса, а не от `Set-Location`:
  пути в таких вызовах только абсолютные.

## Общее с другими pet-проектами

Проект — один из трёх pet-проектов (ClaudeVpnGuard, DevMonitor, AgentGlow), они устроены одинаково: похожий
интерфейс, одинаковые установщик, деинсталлятор, порядок меню и код общих частей.

- **Общие файлы** — одинаковые во всех, отличается только `namespace`:
  `installer\setup\{SetupForm, Installation, InstallTarget, Payload, SetupOption, SetupField,
  InstallRequest, SetupProgram, SetupLog}.cs`, `installer\common\{UninstallRegistration, RunningApp}.cs`,
  `installer\uninstall\UninstallProgram.cs`, `src\{AboutForm, CrashReportConsent, CrashUploader}.cs`.
  `installer\make-payload.ps1` отличается только переменными в начале. `build.cmd` и `build-installer.cmd` у AgentGlow
  свои (рекурсивная сборка, общий список исходников для установщика). Поменял общий файл — та же правка в других
  проектах.
- **Своё у проекта:** `src\AppIdentity.cs` (имя, версия, ссылки, пути), `src\Autostart.cs`,
  `installer\setup\SetupProfile.cs` (тексты, галочки по каталогу источников), `installer\uninstall\UninstallProfile.cs`,
  `installer\payload.txt` (что ставится), `src\CrashReport.cs` (перехват падений).
- **Надёжность:**
  - журнал `log.txt` пишет запуск (версия, пользователь, Windows, настройки), шаги запуска и причину
    каждого отказа — по нему «не завелось» разбирается без догадок;
  - `Program.cs` перехватывает падения (`AppDomain.UnhandledException` с
    `[HandleProcessCorruptedStateExceptions]`, `Application.ThreadException`), `CrashReport` пишет
    стек в журнал и показывает окно; отчёт на `AppIdentity.SiteUrl + "crash-report"` — только по
    согласию из установщика (галочка по умолчанию выключена), один раз, без повторов;
  - опасные системные вызовы не должны молча убивать программу: отдельный процесс с таймаутом или
    перехват плюс метка «прошлый запуск умер здесь»;
  - сбои окружения программа по возможности лечит сама; проблема и починка видны на значке в трее
    (метки ошибки и починки), в подсказке, меню и журнале. Свои проблемы — только в трее и
    уведомлениях, не в основном результате программы.
- **Меню трея:** блок состояния; действия приложения; «Настройки…», «Журнал» (если есть),
  «Запускать при входе в Windows», «О приложении…»; «Выход».
- **Установщик:** права администратора, выбор папки (по умолчанию `C:\Program Files\<Имя>`), галочки
  проекта, галочка автозапуска, сам останавливает запущенную копию, после установки запускает программу. Регистрация
  в «Приложениях» — в HKLM. Деинсталлятор сам закрывает программу и удаляет её данные.
- **Установка поверх любой прежней версии обязана работать** (кроме ClaudeGlow до 2.0 — решение пользователя
  08.10.2026: старые версии удалены, совместимость с ними не нужна): установщик сам останавливает запущенную копию,
  заменяет файлы, пересоздаёт задачи Планировщика и записи реестра (`/F`, перезапись), настройки старых версий
  читаются — незнакомые ключи пропускаются, пропавшие берут значения по умолчанию, форматы данных остаются читаемыми
  или переводятся при запуске. Удалять старую версию перед установкой пользователь не должен никогда. Перед релизом —
  установка поверх предыдущего релиза и проверка журнала.
- **Любая правка доводится до конца:** версия в `AppIdentity.Version` и трёх `AssemblyInfo.cs`, запись
  в `CHANGELOG.md`, сборка `build-installer.cmd`, проверка Защитником, коммит и push, Release на
  GitHub с установщиком, при необходимости — README, скриншоты в `docs\` и страница на
  aokazantsev.ru/pets.
